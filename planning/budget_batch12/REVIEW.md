## (b) Decisions for Youri

1. **Italy + Slovenia + Croatia: priced as fly-in Venice + rental to Zagreb, not own car.** The keyword guess said own_car, but the route text says "fly home from Zagreb". Rental 10 days (day 3 to 12) × 45 + drop IT→HR est 120 + fuel 850 km + tolls = 724. If it really is an own car from NL: drive in/out ≈ 1180/1370 km (≈ 200-240 each way incl. AT/SI vignettes) and in-route ≈ 160, so ≈ 600 total instead of 230 + 724.
2. **One-way international drop fees are estimates (100-250)**: SI→ME 250 (Grand Balkan; many firms ban BA/ME) and 200 (SI-HR-ME), IT→HR 120, SI→HR 100, XK→ME 100, AL→MK 150, MK→GR 120, 60 cross-border permits for the 4-country Serbia loop. Real quotes can differ by ±50%; they are the biggest soft spot in this batch.
3. **Rental days are my call (notes never say)**: city days without a car are excluded (Ljubljana, Venice, Belgrade, Tirana, Skopje, Dubrovnik). Grand Balkan 10, Italy 10, SI-HR-ME 8, SI-Istria 7, Albania+MK 7, Serbia loop 10, Kosovo+ME 8, Montenegro 5, Istria 4, North Macedonia 4, Plitvice 3, Skopje+Ohrid 3, MK+Greece 3. Each day more/less = about the daily rate (30-48).
4. **Kilometres changed where the input missed the return**: input km is stops in order, no way back to the airport. I used own road estimates for loops that fly out of the pick-up airport: Istria 250 (input 100), Plitvice 300 (180), Montenegro 6d 480 (210), North Macedonia 410 (220), Skopje+Ohrid 370 (180), Kosovo+ME 540 (260), SI-Istria 340 (290). Effect is only fuel/tolls, 10-40 each.
5. **Montenegro + Croatia: no car**. Text never mentions one; all stops are bus-reachable (Dubrovnik-Kotor bus 20 est). Rental would add ≈ 250-300. Same logic could apply to Plitvice+Zagreb (bus ≈ 25 return vs 195 car) and Skopje+Ohrid (bus ≈ 20 vs 138); I kept the rental because the mode says rental.
6. **Montenegro Roadtrip: car in daily rate (€50-60/day incl. rental)** so nothing added. Plitvice: park fee (€10-40 by season) NOT added because the notes say the budget already runs higher for it. Fruška Gora, Brijuni, Vis, Mavrovo, Gjirokastër: no price in notes, not priced.
7. **Fares**: Tivat and Pristina have no nonstops, so 160-170 / 120. Backs without a separate search are estimated from the out fare (-10, "est"). Kotor-ending routes use Tivat; Montenegro-based loops use Podgorica.
8. **Public-transport legs estimated** (no price in notes): Split islands 38 (only the Hvar catamaran 15.5 is from notes, midpoint of 6-25), Kotor local 15, Belgrade-Novi Sad 8, N. Macedonia + Albania local 10+10 (cross-border bus 9.5 is from notes).
9. Kotor city walls 11.5 (notes €8-15 midpoint) added as an activity on the Kotor route only. Montenegro 6d park pass 13.5 (notes).

- Block 1 of the Italy+SI+HR route says "Drive via Trieste", Trieste is listed as a waypoint inside a Slovenia block (Italy km = 0 in input). Mode keyword says own_car but text says fly home from Zagreb.
- Grand Balkan Roadtrip: block 3 says "fly home from Podgorica or Tivat" but the route is rental one-way from Ljubljana: the drop fee is not mentioned anywhere.
